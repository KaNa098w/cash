# Пробный сборщик DNS для обычного Chrome

Первый этап: одна открытая страница каталога DNS, ручная проверка и сохранение
карточек в локальную базу. Telegram-публикации и автоматический обход отключены.
Куки, пароли, история браузера и содержимое других вкладок не передаются.

## Установка вручную

1. Запустите `discount_bot/start_bridge.cmd`. Это только локальный приёмник.
2. В обычном Chrome откройте `chrome://extensions`.
3. Включите «Режим разработчика» и нажмите «Загрузить распакованное расширение».
4. Выберите именно эту папку: `D:\Programs\pos_cash\cash\discount_bot\chrome_bridge`.
5. Откройте DNS, выберите Шымкент, затем категорию с товарами и полными ценами.
6. Нажмите значок расширения через кнопку пазла в Chrome.
7. Скопируйте содержимое `discount_bot/data/bridge_pairing.txt` в поле ключа.
   Это отдельный ключ локального подключения, не токен Telegram.
8. Нажмите «1. Проверить страницу», проверьте названия и цены в предпросмотре.
9. Нажмите «2. Сохранить в бота». Появится число сохранённых товаров и скидок от 20%.

Повторные карточки на одной странице объединяются по ссылке. Повторное сохранение
создаёт новое наблюдение цены. Ничего не отправляется в Telegram и не добавляется
в очередь публикации. Основной бот остаётся выключенным.

Если найдено 0 карточек или не прочитан город, расширение остановится. Не выбирайте
другой город ради получения данных. Сообщите текст результата — потребуется
уточнить селекторы текущей версии DNS. Работа в настоящем пользовательском Chrome
подтверждается только после этой проверки.

Локальный сервер слушает только `127.0.0.1:8765`, требует ключ и запрос от расширения.
Расширение не обращается к внешним сервисам. Разрешение activeTab действует на
выбранную пользователем вкладку; код дополнительно разрешает только www.dns-shop.kz.
Не отключайте защиту Chrome или сайта. Проверки человека проходятся вручную.

Остановка приёмника: Ctrl+C в его окне. Он не заменяет обычный запуск бота.
